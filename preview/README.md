# Layout preview

Open [index.html](index.html) in a browser to inspect the current library and notebook layouts. This HTML, CSS and JavaScript preview illustrates visual hierarchy and selected interactions; it does not edit or save documents. The latest library capture is [preview-library-v5.png](preview-library-v5.png), and the latest notebook capture is [preview-caderno-v6.png](preview-caderno-v6.png). Earlier captures remain available for comparison.

The preview uses IBM Plex and Phosphor Icons from online CDNs, so those assets need an internet connection. The desktop application is planned to bundle its assets locally. The design rationale is in the [layout document](../docs/01-layout-refeito.md).
